# ТЗ: liquid glass + растения из Telegram

## Дизайн
- Liquid glass через библиотеку Haze: размытие, полупрозрачные карточки, тонкая светлая обводка, блик.
- Фон — фиолетовый градиент с размытыми цветными пятнами. Основной цвет `#7C4DFF`.
- Dynamic color выключен. Целевые устройства — Android 16+.
- Тема: Системная / Светлая / Тёмная. Иконка ☀️/🌙 в шапке, полный выбор в настройках, выбор сохраняется.

## Telegram (TDLib, только arm64-v8a)
- На вкладке «Форма» раздел «Telegram»: поля `api_id` и `api_hash` (пользователь получает их сам на my.telegram.org).
- Вход: телефон → код → 2FA. Сессия сохраняется.
- Затем выбор чата из списка с поиском и выбор **темы** (в группе есть темы).

## Ожидание
- Переключатель «Следить за каналом» на вкладке «Запуск». Включается сам после настройки Telegram.
- В 13:59 МСК срабатывает точный будильник и запускается foreground-сервис с уведомлением «Жду растения».
- 13:59:00–14:00:00 — проверка каждую секунду. Дальше — мгновенные обновления TDLib плюс проверка раз в 30 с до **14:30**.
- Если к 14:30 поста нет — тихое уведомление «Сегодня растений не было», следующая попытка завтра в 13:59.
- При ручном открытии приложения сегодняшний пост проверяется всегда.
- При первом включении приложение один раз просит разрешение на точные будильники и исключение из оптимизации батареи.

## Пост
- Сегодняшний по МСК, из выбранной темы. Автор любой.
- Растения — строки, начинающиеся с ✅ или ✔️.
- Разбор строки: название, контейнер (`C5`, `C7,5`), размер (`30/40`, `25/-`), пометки (`один в руки`, `new`, `(staked)`).
- Берётся самый свежий подходящий пост дня, правки тоже учитываются. Если выбранное растение пропало из списка — уведомление «Список изменился».
- Ссылка на форму из поста (`forms.gle`) раскрывается и сравнивается с сохранённой по ID формы. При отличии сохраняется в настройках навсегда, в журнал пишется запись.

## Выбор и заполнение
- Уведомление «🌱 Растения появились» со звуком, по нажатию открывается карточка «Сегодня в продаже» на вкладке «Запуск».
- Отметить можно не больше 2 растений. Порядок отметки = порядок отправки. Контейнер, размер и пометки показаны чипами, «один в руки» выделено отдельно.
- «Заполнить» запускает текущий BotEngine (ждёт открытия формы). Ручные поля «Растение 1/2» остаются запасным вариантом.
- Сопоставление с вариантами выпадающего списка строгое: название + контейнер + размер. Нормализация: регистр, пробелы, С(кирилл.)→C, `,`↔`.`, ’→', Ø≈O. Пометки в сравнении не участвуют.
- Если варианта ещё нет, форма перезагружается каждые checkInterval до 5 минут. Если варианта так и нет или подходят два — ошибка и уведомление. Второе растение всё равно отправляется.

## Проверка
- В реальную форму питомника **ничего не отправлять** из тестов, смотреть можно.
- Разбор постов и сопоставление проверяются офлайн на фикстурах.
- Полный прогон — на тестовой копии формы и тестовом канале, которые пришлёт пользователь.
