# FormBot для Android

Заполняет Google-форму прямо с телефона — без браузера и без компьютера.

## Установка
1. Перекиньте `FormBot.apk` на телефон (Telegram «Избранное», Google Drive, кабель).
2. Откройте файл. Android попросит разрешить установку из этого источника — разрешите.
3. При первом запуске разрешите уведомления: через них бот зовёт вас, когда ИИ не знает ответа.

## Первая настройка
- **Быстро:** вкладка «Форма» → «Импортировать настройки» → выберите `form_bot_config.json`
  с компьютера. Подтянутся ссылка, растения, ник, столбик, готовые ответы и ключи ИИ.
- **Вручную:** «Форма» — ссылка и данные; «ИИ» — ключи провайдеров.
  Кнопка «Проверить провайдеров» покажет, какие работают.

## Растения из Telegram
1. Получите `api_id` и `api_hash` на https://my.telegram.org → API development tools.
2. «Форма» → «Telegram»: введите ключи → «Подключить» → номер → код из Telegram → облачный пароль (если есть).
3. «Выбрать чат» → чат питомника → тему с предложениями. Слежение включится само.
4. Каждый день в 13:59 МСК приложение ждёт пост (до 14:30). Появились растения — придёт уведомление;
   на «Запуске» отметьте до двух (порядок отметки = порядок отправки) и нажмите «Заполнить».
   Если после «Получить код» висит «Подключаюсь к серверам Telegram…» — серверы недоступны напрямую:
   включите VPN или вставьте в поле «Прокси» ссылку `tg://proxy?…` / `socks5://…` и нажмите «Применить прокси».
5. Один раз разрешите работу без ограничений батареи — иначе Android может задержать проверку.

## Работа
Без Telegram: «Запуск» → **Запустить вручную** (растения из полей «Растения вручную»). Бот ждёт открытия формы (можно заблокировать экран),
заполняет и отправляет. Ход работы — в журнале и в уведомлении.
Если ИИ не знает ответа — придёт уведомление, ответ вводится в карточке на экране.

## Что не поддерживается
- Формы, требующие входа в Google-аккаунт.
- Вопросы с загрузкой файла.

## Сборка (для разработчика)
```
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest   # тесты ядра
```
